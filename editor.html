Paste from a spreadsheet

  1. Download the spreadsheet template and open it in Google Sheets or Excel (in Google Sheets: File → Import → Upload).
  2. Fill in one row per clue. Columns: Round (1, 2 or Final), Category, Value, Clue, Response, Double Down (yes or blank). Blank Round or Category cells repeat the row above.
  3. Select the rows, including the header, copy them, and paste below.
  4. Want to try it first? Download the sample board: a full game ready to paste or open in a spreadsheet.
